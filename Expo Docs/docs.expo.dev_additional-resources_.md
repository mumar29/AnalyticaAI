# Additional resources
[Edit this page](https://docs.expo.dev/additional-resources/<https:/github.com/expo/expo/edit/main/docs/pages/additional-resources.mdx> "Edit content of this page on GitHub")
A reference of resources that are useful to learn about Expo tooling and services.
[Edit this page](https://docs.expo.dev/additional-resources/<https:/github.com/expo/expo/edit/main/docs/pages/additional-resources.mdx> "Edit content of this page on GitHub")
The following resources are useful for learning about Expo tooling and services.
## External resources[](https://docs.expo.dev/additional-resources/<#external-resources>)
### Expo team communication[](https://docs.expo.dev/additional-resources/<#expo-team-communication>)
  * [Blog](https://docs.expo.dev/additional-resources/<https:/expo.dev/blog>) - Our official blog, where we post release notes every month and other Expo related content at random intervals.
  * [Changelog](https://docs.expo.dev/additional-resources/<https:/expo.dev/changelog>) - Our official changelog, where we post information about EAS, web dashboard and other Expo services related changes at random intervals.


### GitHub[](https://docs.expo.dev/additional-resources/<#github>)
  * [expo/expo](https://docs.expo.dev/additional-resources/<https:/github.com/expo/expo>) - Expo Go, SDK, Docs, and the Expo CLI.
  * [expo/eas-cli](https://docs.expo.dev/additional-resources/<https:/github.com/expo/eas-cli>) - The fastest way to build, submit, and update Android and iOS apps.
  * [expo/examples](https://docs.expo.dev/additional-resources/<https:/github.com/expo/examples>) - Integrations and other examples.
  * [expo/config-plugins](https://docs.expo.dev/additional-resources/<https:/github.com/expo/config-plugins>) - Expo Config Plugins for working with third-party packages.
  * [expo/snack](https://docs.expo.dev/additional-resources/<https:/github.com/expo/snack>) - Build apps from the browser.
  * [expo/vscode-expo](https://docs.expo.dev/additional-resources/<https:/github.com/expo/vscode-expo>) - VS Code extension for working with Expo tools.
  * [expo/vscode-expo-theme](https://docs.expo.dev/additional-resources/<https:/github.com/expo/vscode-expo-theme>) - VS Code theme created by Expo team.
  * [expo/fyi](https://docs.expo.dev/additional-resources/<https:/github.com/expo/fyi>) - Troubleshooting guides for Expo tools and services.
  * [expo/orbit](https://docs.expo.dev/additional-resources/<https:/github.com/expo/orbit>) - Launch builds and start simulators from your macOS menu bar and Windows task bar.
