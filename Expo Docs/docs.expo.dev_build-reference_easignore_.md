# Ignore files via .easignore
[Edit this page](https://docs.expo.dev/build-reference/easignore/<https:/github.com/expo/expo/edit/main/docs/pages/build-reference/easignore.mdx> "Edit content of this page on GitHub")
Learn how to configure EAS to ignore unnecessary files during the build process.
[Edit this page](https://docs.expo.dev/build-reference/easignore/<https:/github.com/expo/expo/edit/main/docs/pages/build-reference/easignore.mdx> "Edit content of this page on GitHub")
A .easignore file defines which files [EAS](https://docs.expo.dev/build-reference/easignore/<https:/expo.dev/eas>) should ignore when uploading your project to the [EAS Build](https://docs.expo.dev/build-reference/easignore/</build/introduction>) servers.
> Ignoring unnecessary files can help reduce your app's archive size and upload time.
By default, the [EAS CLI](https://docs.expo.dev/build-reference/easignore/</build/setup#install-the-latest-eas-cli>) refers to the [.gitignore](https://docs.expo.dev/build-reference/easignore/<https:/git-scm.com/docs/gitignore>) file (if it exists) to determine which files to ignore. If you create a .easignore file, the EAS CLI prioritizes it over the .gitignore file. When creating a .easignore file, include all files and directories from your .gitignore file and add additional files you want to ignore.
1
Create a .easignore file in the root of your project.
2
Copy the content of the .gitignore file into the .easignore file. Then, add any files that are unnecessary for the build process.
.easignore
Copy
```
# Copy everything from your .gitignore file here
# Additional ignores specific to EAS builds
# Ignore native directories (if you are using EAS Build)
/android
/ios
# Ignore test coverage reports
/coverage

```

If your project does not contain android and ios directories, [EAS Build will run Prebuild](https://docs.expo.dev/build-reference/easignore/</workflow/prebuild#usage-with-eas-build>) to generate these native directories before compilation.
3
Save the file and trigger a new build.
Terminal
Copy
`- ``eas build --platform ios --profile development`
You've successfully configured your .easignore file.
