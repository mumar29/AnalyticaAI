# EAS Build
[Edit this page](https://docs.expo.dev/build/<https:/github.com/expo/expo/edit/main/docs/pages/build/introduction.mdx> "Edit content of this page on GitHub")
EAS Build is a hosted service for building app binaries for your Expo and React Native projects.
[Edit this page](https://docs.expo.dev/build/<https:/github.com/expo/expo/edit/main/docs/pages/build/introduction.mdx> "Edit content of this page on GitHub")
EAS Build is a hosted service for building app binaries for your Expo and React Native projects.
It makes building your apps for distribution simple and easy to automate by providing defaults that work well for Expo and React Native projects out of the box, and by handling your app signing credentials for you (if you wish). It also makes sharing builds with your team easier than ever with [internal distribution](https://docs.expo.dev/build/</build/internal-distribution>) (using ad hoc and/or enterprise "universal" provisioning), deeply integrates with EAS Submit for app store submissions, and has first-class support for the `expo-updates`[](https://docs.expo.dev/build/</build/updates>) library.
It's designed to work for any native project, whether or not you use Expo and React Native. It's the fastest way to get from `npx create-expo-app` or `npx @react-native-community/cli@latest init` to app stores.
