# Create a project
[Edit this page](https://docs.expo.dev/get-started/create-a-project/<https:/github.com/expo/expo/edit/main/docs/pages/get-started/create-a-project.mdx> "Edit content of this page on GitHub")
Learn how to create a new Expo project.
[Edit this page](https://docs.expo.dev/get-started/create-a-project/<https:/github.com/expo/expo/edit/main/docs/pages/get-started/create-a-project.mdx> "Edit content of this page on GitHub")
System requirements:
  * [Node.js (LTS)](https://docs.expo.dev/get-started/create-a-project/<https:/nodejs.org/en/>).
  * macOS, Windows (Powershell and [WSL 2](https://docs.expo.dev/get-started/create-a-project/<https:/expo.fyi/wsl>)), and Linux are supported.


We recommend starting with the default project created by `create-expo-app`. The default project includes example code to help you get started.
To create a new project, run the following command:
Terminal
Copy
`- ``npx create-expo-app@latest`
> You can choose a different template by adding the `--template`[ option](https://docs.expo.dev/get-started/create-a-project/</more/create-expo#--template>).
