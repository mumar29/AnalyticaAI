# Next steps
[Edit this page](https://docs.expo.dev/get-started/next-steps/<https:/github.com/expo/expo/edit/main/docs/pages/get-started/next-steps.mdx> "Edit content of this page on GitHub")
Develop, review, and submit your project.
[Edit this page](https://docs.expo.dev/get-started/next-steps/<https:/github.com/expo/expo/edit/main/docs/pages/get-started/next-steps.mdx> "Edit content of this page on GitHub")
Here are next steps to continue building your app:
### Reset your project[](https://docs.expo.dev/get-started/next-steps/<#reset-your-project>)
You can remove the boilerplate code and start fresh with a new project. Run the following command to reset your project:
Terminal
Copy
`- ``npm run reset-project`
This command will move the existing files in app to app-example, then create a new app directory with a new index.tsx file.
### Develop, review, and deploy[](https://docs.expo.dev/get-started/next-steps/<#develop-review-and-deploy>)
Learn how to develop by reading the docs in the Develop section. You'll learn how to create [UI elements](https://docs.expo.dev/get-started/next-steps/</develop/user-interface/splash-screen-and-app-icon>), add [unit tests](https://docs.expo.dev/get-started/next-steps/</develop/unit-testing>), include [native modules](https://docs.expo.dev/get-started/next-steps/</config-plugins/introduction>), and more.
Once you've developed your app, you can share it with your teammates for [review](https://docs.expo.dev/get-started/next-steps/</review/overview>).
Finally, you can [build](https://docs.expo.dev/get-started/next-steps/</deploy/build-project>) and [submit](https://docs.expo.dev/get-started/next-steps/</deploy/submit-to-app-stores>) your project to the app stores.
### Step-by-step guide[](https://docs.expo.dev/get-started/next-steps/<#step-by-step-guide>)
For a guided, step-by-step walkthrough of building an app with Expo from start to finish, check out the [tutorial](https://docs.expo.dev/get-started/next-steps/</tutorial/introduction>).
