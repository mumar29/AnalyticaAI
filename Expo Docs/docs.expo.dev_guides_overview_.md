# Guides: Overview
[Edit this page](https://docs.expo.dev/guides/overview/<https:/github.com/expo/expo/edit/main/docs/pages/guides/overview.mdx> "Edit content of this page on GitHub")
[Edit this page](https://docs.expo.dev/guides/overview/<https:/github.com/expo/expo/edit/main/docs/pages/guides/overview.mdx> "Edit content of this page on GitHub")
This section contains information about the development with Expo and Expo Application Services (EAS):
### Development process[](https://docs.expo.dev/guides/overview/<#development-process>)
Learn about the process of [building an app with Expo](https://docs.expo.dev/guides/overview/</workflow/overview>) to help understand the mental model of the core development loop. This section also dives into additional configurations and workflows you may require during the development process to help you develop, deploy, and maintain your app. It contains in-depth information about [app config](https://docs.expo.dev/guides/overview/</workflow/configuration>), [permissions](https://docs.expo.dev/guides/overview/</guides/permissions>), [universal links](https://docs.expo.dev/guides/overview/</guides/deep-linking>), [custom native code](https://docs.expo.dev/guides/overview/</workflow/continuous-native-generation>), [web](https://docs.expo.dev/guides/overview/</workflow/web>), and more.
### Expo Router[](https://docs.expo.dev/guides/overview/<#expo-router>)
Learn about using different navigation functionalities from the [Expo Router](https://docs.expo.dev/guides/overview/</router/advanced/root-layout>) library. It also covers a comprehensive [Hooks API](https://docs.expo.dev/guides/overview/</router/reference/hooks>) that the library provides and other aspects of navigation such as [Authentication](https://docs.expo.dev/guides/overview/</router/reference/authentication>), [Redirects](https://docs.expo.dev/guides/overview/</router/reference/redirects>), [Testing](https://docs.expo.dev/guides/overview/</router/reference/testing>), and more.
### Expo Modules API[](https://docs.expo.dev/guides/overview/<#expo-modules-api>)
Learn how to add and use Native modules in your app using [Expo Modules API](https://docs.expo.dev/guides/overview/</modules/overview>).
### Other content[](https://docs.expo.dev/guides/overview/<#other-content>)
Apart from the essentials listed above, there are plenty of other features to explore such as [Push notifications](https://docs.expo.dev/guides/overview/</push-notifications/overview>) and best practices on [distributing your app](https://docs.expo.dev/guides/overview/</distribution/introduction>) to the app stores. We also have a collection of guides in the Assorted and third-party Integrations sections.
