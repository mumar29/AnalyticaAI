[Edit this page](https://docs.expo.dev/regulatory-compliance/gdpr/<https:/github.com/expo/expo/edit/main/docs/pages/regulatory-compliance/gdpr.mdx> "Edit content of this page on GitHub")
## Are apps built with Expo GDPR compliant?[](https://docs.expo.dev/regulatory-compliance/gdpr/<#are-apps-built-with-expo-gdpr-compliant>)
They can be! You can build GDPR compliant apps with Expo if you follow the requirements.
While Expo ensures the proper handling and processing of developer data and end-user data, we cannot guarantee that the developers who build apps with Expo follow similar data privacy practices themselves.
[European Commission's data protection pageFor more information about GDPR, see European Commission's data protection page.](https://docs.expo.dev/regulatory-compliance/gdpr/<https:/ec.europa.eu/info/law/law-topic/data-protection_en>)
