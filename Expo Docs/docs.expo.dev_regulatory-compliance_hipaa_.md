# HIPAA compliance and Expo
[Edit this page](https://docs.expo.dev/regulatory-compliance/hipaa/<https:/github.com/expo/expo/edit/main/docs/pages/regulatory-compliance/hipaa.mdx> "Edit content of this page on GitHub")
Learn about how applications built with Expo can be HIPAA compliant.
[Edit this page](https://docs.expo.dev/regulatory-compliance/hipaa/<https:/github.com/expo/expo/edit/main/docs/pages/regulatory-compliance/hipaa.mdx> "Edit content of this page on GitHub")
## Are apps built with Expo HIPAA compliant?[](https://docs.expo.dev/regulatory-compliance/hipaa/<#are-apps-built-with-expo-hipaa-compliant>)
They can be! You can build HIPAA compliant apps with Expo if you follow the requirements.
Expo doesn't collect any individually identifiable health data, and you can see all the data that Expo collects on [our privacy explained page](https://docs.expo.dev/regulatory-compliance/hipaa/<https:/expo.dev/privacy-explained>). That being said, you are ultimately in control of the data you collect from your users, so we cannot guarantee that all apps built with Expo are HIPAA compliant, as in the end, it is up to you as an individual application developer. But there should be no compliance issues with using Expo.
