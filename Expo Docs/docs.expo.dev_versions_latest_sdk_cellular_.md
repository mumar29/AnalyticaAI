# ![Expo Cellular icon](https://docs.expo.dev/static/images/packages/expo-cellular.png)Expo Cellular
[GitHub](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-cellular> "View source code of expo-cellular on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/www.npmjs.com/package/expo-cellular> "View package in npm Registry")
An API that provides information about the user's cellular service provider.
[GitHub](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-cellular> "View source code of expo-cellular on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/www.npmjs.com/package/expo-cellular> "View package in npm Registry")
Android
iOS
Web
`expo-cellular` provides information about the user's cellular service provider, such as its unique identifier, cellular connection type, and whether it allows VoIP calls on its network.

### `Cellular.allowsVoip`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellularallowsvoip>)
Android
iOS
Web
Type: `boolean | null`
Indicates if the carrier allows making VoIP calls on its network. On Android, this checks whether the system supports SIP-based VoIP API. See the [Android documentation](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/developer.android.com/reference/android/net/sip/SipManager.html#isVoipSupported\(android.content.Context\)>) for more information.
On iOS, if you configure a device for a carrier and then remove the SIM card, this property retains the `boolean` value indicating the carrier’s policy regarding VoIP. If you then install a new SIM card, its VoIP policy `boolean` replaces the previous value of this property.
On web, this returns `null`.
Example
```
Cellular.allowsVoip; // true or false

```

> Deprecated Use `getCarrierNameAsync()`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellulargetcarriernameasync>) instead.
### `Cellular.carrier`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellularcarrier>)
Android
iOS
Web
Type: `string | null`
The name of the user’s home cellular service provider. If the device has dual SIM cards, only the carrier for the currently active SIM card will be returned. On Android, this value is only available when the SIM state is `SIM_STATE_READY`[](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/developer.android.com/reference/android/telephony/TelephonyManager.html#SIM_STATE_READY>). Otherwise, this returns `null`.
On iOS, if you configure a device for a carrier and then remove the SIM card, this property retains the name of the carrier. If you then install a new SIM card, its carrier name replaces the previous value of this property. The value for this property is `null` if the user never configured a carrier for the device.
On web, this returns `null`.
Example
```
Cellular.carrier; // "T-Mobile" or "Verizon"

```

> Deprecated Use `getIsoCountryCodeAsync()`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellulargetisocountrycodeasync>) instead.
### `Cellular.isoCountryCode`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellularisocountrycode>)
Android
iOS
Web
Type: `string | null`
The ISO country code for the user’s cellular service provider. On iOS, the value is `null` if any of the following apply:
  * The device is in airplane mode.
  * There is no SIM card in the device.
  * The device is outside of cellular service range.


On web, this returns `null`.
Example
```
Cellular.isoCountryCode; // "us" or "au"

```

### `Cellular.mobileCountryCode`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellularmobilecountrycode>)
Android
iOS
Web
Type: `string | null`
The mobile country code (MCC) for the user’s current registered cellular service provider. On Android, this value is only available when SIM state is `SIM_STATE_READY`[](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/developer.android.com/reference/android/telephony/TelephonyManager.html#SIM_STATE_READY>). Otherwise, this returns `null`. On iOS, the value may be null on hardware prior to iPhone 4S when in airplane mode. Furthermore, the value for this property is `null` if any of the following apply:
  * There is no SIM card in the device.
  * The device is outside of cellular service range.


On web, this returns `null`.
Example
```
Cellular.mobileCountryCode; // "310"

```

### `Cellular.getCellularGenerationAsync()`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellulargetcellulargenerationasync>)
Android
iOS
Web
Returns:
`Promise[](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<CellularGeneration[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellulargeneration>)>`
Returns a promise which fulfils with a `Cellular.CellularGeneration`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellulargeneration>) enum value that represents the current cellular-generation type.
You will need to check if the native permission has been accepted to obtain generation. If the permission is denied `getCellularGenerationAsync` will resolve to `Cellular.Cellular Generation.UNKNOWN`.
On web, this method uses `navigator.connection.effectiveType`[](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/developer.mozilla.org/en-US/docs/Web/API/NetworkInformation/effectiveType>) to detect the effective type of the connection using a combination of recently observed round-trip time and downlink values. See [here](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/developer.mozilla.org/en-US/docs/Web/API/Network_Information_API>) to view browser compatibility.
Example
```
await Cellular.getCellularGenerationAsync();
// CellularGeneration.CELLULAR_4G

```

### `Cellular.getMobileNetworkCodeAsync()`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellulargetmobilenetworkcodeasync>)
Android
iOS
Web
Returns:
`Promise[](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<string | null>`
Returns the mobile network code (MNC) for the user’s current registered cellular service provider.
On Android, this value is only available when SIM state is `SIM_STATE_READY`[](https://docs.expo.dev/versions/latest/sdk/cellular/<https:/developer.android.com/reference/android/telephony/TelephonyManager.html#SIM_STATE_READY>). Otherwise, this returns `null`. On iOS, the value may be null on hardware prior to iPhone 4S when in airplane mode. Furthermore, the value for this property is `null` if any of the following apply:
  * There is no SIM card in the device.
  * The device is outside of cellular service range.


On web, this returns `null`.
Example
```
await Cellular.getMobileNetworkCodeAsync(); // "310"

```

## Enums[](https://docs.expo.dev/versions/latest/sdk/cellular/<#enums>)
### `CellularGeneration`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellulargeneration>)
Android
iOS
Web
Describes the current generation of the cellular connection. It is an enum with these possible values:
#### `UNKNOWN`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#unknown>)
`CellularGeneration.UNKNOWN ＝ 0`
Either we are not currently connected to a cellular network or type could not be determined.
#### `CELLULAR_2G`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellular_2g>)
`CellularGeneration.CELLULAR_2G ＝ 1`
Currently connected to a 2G cellular network. Includes CDMA, EDGE, GPRS, and IDEN type connections.
#### `CELLULAR_3G`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellular_3g>)
`CellularGeneration.CELLULAR_3G ＝ 2`
Currently connected to a 3G cellular network. Includes EHRPD, EVDO, HSPA, HSUPA, HSDPA, HSPAP, and UTMS type connections.
#### `CELLULAR_4G`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellular_4g>)
`CellularGeneration.CELLULAR_4G ＝ 3`
Currently connected to a 4G cellular network. Includes LTE type connections.
#### `CELLULAR_5G`[](https://docs.expo.dev/versions/latest/sdk/cellular/<#cellular_5g>)
`CellularGeneration.CELLULAR_5G ＝ 4`
Currently connected to a 5G cellular network. Includes NR and NRNSA type connections.
