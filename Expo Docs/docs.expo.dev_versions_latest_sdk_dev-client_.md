# ![Expo DevClient icon](https://docs.expo.dev/static/images/packages/expo-dev-client.png)Expo DevClient
[GitHub](https://docs.expo.dev/versions/latest/sdk/dev-client/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-dev-client> "View source code of expo-dev-client on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/dev-client/<https:/www.npmjs.com/package/expo-dev-client> "View package in npm Registry")
A library that allows creating a development build and includes useful development tools.
[GitHub](https://docs.expo.dev/versions/latest/sdk/dev-client/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-dev-client> "View source code of expo-dev-client on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/dev-client/<https:/www.npmjs.com/package/expo-dev-client> "View package in npm Registry")
Android
iOS
`expo-dev-client` adds various useful development tools to your debug builds:
  * A configurable launcher UI, so you can launch updates (such as from [PR previews](https://docs.expo.dev/versions/latest/sdk/dev-client/</develop/development-builds/development-workflows#pr-previews>)) and switch between development servers without needing to recompile the native app
  * Improved debugging tools (such as support for [inspecting network requests](https://docs.expo.dev/versions/latest/sdk/dev-client/</debugging/tools#inspecting-network-requests>))
  * [A powerful and extensible developer menu UI](https://docs.expo.dev/versions/latest/sdk/dev-client/</debugging/tools#developer-menu>)


Expo documentation refers to debug builds that include `expo-dev-client` as [development builds](https://docs.expo.dev/versions/latest/sdk/dev-client/</develop/development-builds/introduction>).
## Installation[](https://docs.expo.dev/versions/latest/sdk/dev-client/<#installation>)
Terminal
Copy
`- ``npx expo install expo-dev-client`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/latest/sdk/dev-client/</bare/overview>), start by installing `expo`[](https://docs.expo.dev/versions/latest/sdk/dev-client/</bare/installing-expo-modules>) in your project. Then, follow the instructions from [Install `expo-dev-client` in an existing React Native project](https://docs.expo.dev/versions/latest/sdk/dev-client/</bare/install-dev-builds-in-bare>).
## Configuration in app config[](https://docs.expo.dev/versions/latest/sdk/dev-client/<#configuration-in-app-config>)
You can configure development client launcher using its built-in [config plugin](https://docs.expo.dev/versions/latest/sdk/dev-client/</config-plugins/introduction>) if you use config plugins in your project ([EAS Build](https://docs.expo.dev/versions/latest/sdk/dev-client/</build/introduction>) or `npx expo run:[android|ios]`). The plugin allows you to configure various properties that cannot be set at runtime and require building a new app binary to take effect.
### Example app.json with config plugin[](https://docs.expo.dev/versions/latest/sdk/dev-client/<#example-appjson-with-config-plugin>)
app.json
Copy
```
{
 "expo": {
  "plugins": [
   [
    "expo-dev-client",
    {
     "launchMode": "most-recent"
    }
   ]
  ]
 }
}

```

### Configurable properties[](https://docs.expo.dev/versions/latest/sdk/dev-client/<#configurable-properties>)
Name| Default| Description  
---|---|---  
`launchMode`| `"most-recent"`| Determines whether to launch the most recently opened project or navigate to the launcher screen.
  * `most-recent` - Attempt to launch directly into a previously opened project and if unable to connect, fall back to the launcher screen.
  * `launcher` - Opens the launcher screen.

  
`addGeneratedScheme`| `true`| By default, `expo-dev-client` will register a custom URL scheme to open a project. Set this property to `false` to disable this scheme.
