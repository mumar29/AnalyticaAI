# ![Expo Font icon](https://docs.expo.dev/static/images/packages/expo-font.png)Expo Font
[GitHub](https://docs.expo.dev/versions/latest/sdk/font/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-font> "View source code of expo-font on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/font/<https:/www.npmjs.com/package/expo-font> "View package in npm Registry")
A library that allows loading fonts at runtime and using them in React Native components.
[GitHub](https://docs.expo.dev/versions/latest/sdk/font/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-font> "View source code of expo-font on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/font/<https:/www.npmjs.com/package/expo-font> "View package in npm Registry")
Android
iOS
tvOS
Web
`expo-font` allows loading fonts from the web and using them in React Native components. See more detailed usage information in the [Fonts](https://docs.expo.dev/versions/latest/sdk/font/</develop/user-interface/fonts>) guide.
## Installation[](https://docs.expo.dev/versions/latest/sdk/font/<#installation>)
Terminal
Copy
`- ``npx expo install expo-font`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/latest/sdk/font/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/latest/sdk/font/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/latest/sdk/font/<https:/github.com/expo/expo/tree/main/packages/expo-font>) as mentioned by the library's README under "Installation in bare React Native projects" section.
## Configuration in app config[](https://docs.expo.dev/versions/latest/sdk/font/<#configuration-in-app-config>)
The recommended way to add fonts to your app is through `expo-font` built-in [config plugin](https://docs.expo.dev/versions/latest/sdk/font/</config-plugins/introduction>) if you use config plugins in your project ([EAS Build](https://docs.expo.dev/versions/latest/sdk/font/</build/introduction>) or `npx expo run: [android|ios]`). The plugin allows you to embed font files at build time which is more efficient than using `loadAsync`[](https://docs.expo.dev/versions/latest/sdk/font/</versions/latest/sdk/font#loadasyncfontfamilyorfontmap-source>). See the [Fonts](https://docs.expo.dev/versions/latest/sdk/font/</develop/user-interface/fonts#with-expo-font-config-plugin>) guide on how to use it.

## Usage[](https://docs.expo.dev/versions/latest/sdk/font/<#usage>)
Minimal example of using a custom font
Copy
Open in Snack
```
import { useFonts } from 'expo-font';
import * as SplashScreen from 'expo-splash-screen';
import { useEffect } from 'react';
import { Text, View, StyleSheet } from 'react-native';
SplashScreen.preventAutoHideAsync();
export default function App() {
 const [loaded, error] = useFonts({
  'Inter-Black': require('./assets/fonts/Inter-Black.otf'),
 });
 useEffect(() => {
  if (loaded || error) {
   SplashScreen.hideAsync();
  }
 }, [loaded, error]);
 if (!loaded && !error) {
  return null;
 }
 return (
  <View style={styles.container}><Text style={{ fontFamily: 'Inter-Black', fontSize: 30 }}>Inter Black</Text><Text style={{ fontSize: 30 }}>Platform Default</Text></View>
 );
}
const styles = StyleSheet.create({
 container: {
  flex: 1,
  justifyContent: 'center',
  alignItems: 'center',
 },
});

Show More

```

## Enums[](https://docs.expo.dev/versions/latest/sdk/font/<#enums>)
### `FontDisplay`[](https://docs.expo.dev/versions/latest/sdk/font/<#fontdisplay>)
Web
Sets the [font-display](https://docs.expo.dev/versions/latest/sdk/font/<https:/developer.mozilla.org/en-US/docs/Web/CSS/@font-face/font-display>) for a given typeface. The default font value on web is `FontDisplay.AUTO`. Even though setting the `fontDisplay` does nothing on native platforms, the default behavior emulates `FontDisplay.SWAP` on flagship devices like iOS, Samsung, Pixel, etc. Default functionality varies on One Plus devices. In the browser this value is set in the generated `@font-face` CSS block and not as a style property meaning you cannot dynamically change this value based on the element it's used in.
#### `AUTO`[](https://docs.expo.dev/versions/latest/sdk/font/<#auto>)
`FontDisplay.AUTO ＝ "auto"`
(Default) The font display strategy is defined by the user agent or platform. This generally defaults to the text being invisible until the font is loaded. Good for buttons or banners that require a specific treatment.
#### `BLOCK`[](https://docs.expo.dev/versions/latest/sdk/font/<#block>)
`FontDisplay.BLOCK ＝ "block"`
The text will be invisible until the font has loaded. If the font fails to load then nothing will appear - it's best to turn this off when debugging missing text.
#### `FALLBACK`[](https://docs.expo.dev/versions/latest/sdk/font/<#fallback>)
`FontDisplay.FALLBACK ＝ "fallback"`
Splits the behavior between `SWAP` and `BLOCK`. There will be a [100ms timeout](https://docs.expo.dev/versions/latest/sdk/font/<https:/developers.google.com/web/updates/2016/02/font-display?hl=en>) where the text with a custom font is invisible, after that the text will either swap to the styled text or it'll show the unstyled text and continue to load the custom font. This is good for buttons that need a custom font but should also be quickly available to screen-readers.
#### `OPTIONAL`[](https://docs.expo.dev/versions/latest/sdk/font/<#optional>)
`FontDisplay.OPTIONAL ＝ "optional"`
This works almost identically to `FALLBACK`, the only difference is that the browser will decide to load the font based on slow connection speed or critical resource demand.
#### `SWAP`[](https://docs.expo.dev/versions/latest/sdk/font/<#swap>)
`FontDisplay.SWAP ＝ "swap"`
Fallback text is rendered immediately with a default font while the desired font is loaded. This is good for making the content appear to load instantly and is usually preferred.
## Error codes[](https://docs.expo.dev/versions/latest/sdk/font/<#error-codes>)
Code| Description  
---|---  
ERR_FONT_API| If the arguments passed to `loadAsync` are invalid.  
ERR_FONT_SOURCE| The provided resource was of an incorrect type.  
ERR_WEB_ENVIRONMENT| The browser's `document` element doesn't support injecting fonts.  
ERR_DOWNLOAD| Failed to download the provided resource.  
ERR_FONT_FAMILY| Invalid font family name was provided.  
ERR_UNLOAD| Attempting to unload fonts that haven't finished loading yet.
