# ![Expo KeepAwake icon](https://docs.expo.dev/static/images/packages/expo-keep-awake.png)Expo KeepAwake
[GitHub](https://docs.expo.dev/versions/latest/sdk/keep-awake/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-keep-awake> "View source code of expo-keep-awake on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/keep-awake/<https:/www.npmjs.com/package/expo-keep-awake> "View package in npm Registry")
A React component that prevents the screen from sleeping when rendered.
[GitHub](https://docs.expo.dev/versions/latest/sdk/keep-awake/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-keep-awake> "View source code of expo-keep-awake on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/keep-awake/<https:/www.npmjs.com/package/expo-keep-awake> "View package in npm Registry")
Android
iOS
tvOS
Web
`expo-keep-awake` provides a React hook that prevents the screen from sleeping and a pair of functions to enable this behavior imperatively.
## Installation[](https://docs.expo.dev/versions/latest/sdk/keep-awake/<#installation>)

If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/latest/sdk/keep-awake/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/latest/sdk/keep-awake/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/latest/sdk/keep-awake/<https:/github.com/expo/expo/tree/main/packages/expo-keep-awake>) as mentioned by the library's README under "Installation in bare React Native projects" section.

### Example: functions[](https://docs.expo.dev/versions/latest/sdk/keep-awake/<#example-functions>)
Keep Awake functions
Copy
Open in Snack
```
import { activateKeepAwake, deactivateKeepAwake } from 'expo-keep-awake';
import React from 'react';
import { Button, View } from 'react-native';
export default class KeepAwakeExample extends React.Component {
 render() {
  return (
   <View style={{ flex: 1, alignItems: 'center', justifyContent: 'center' }}><Button onPress={this._activate} title="Activate" /><Button onPress={this._deactivate} title="Deactivate" /></View>
  );
 }
 _activate = () => {
  activateKeepAwake();
  alert('Activated!');
 };
 _deactivate = () => {
  deactivateKeepAwake();
  alert('Deactivated!');
 };
}
```

### `KeepAwake.activateKeepAwake(tag)`[](https://docs.expo.dev/versions/latest/sdk/keep-awake/<#keepawakeactivatekeepawaketag>)
Android
iOS
tvOS
Web
Parameter| Type| Description  
---|---|---  
tag(optional)| `string`| Tag to lock screen sleep prevention. If not provided, the default tag is used.Default:`ExpoKeepAwakeTag`  
Prevents the screen from sleeping until `deactivateKeepAwake` is called with the same `tag` value.
If the `tag` argument is specified, the screen will not sleep until you call `deactivateKeepAwake` with the same `tag` argument. When using multiple `tags` for activation you'll have to deactivate each one in order to re-enable screen sleep. If tag is unspecified, the default `tag` is used.
Web support [is limited](https://docs.expo.dev/versions/latest/sdk/keep-awake/<https:/caniuse.com/wake-lock>).
Returns:
`Promise[](https://docs.expo.dev/versions/latest/sdk/keep-awake/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<void>`
