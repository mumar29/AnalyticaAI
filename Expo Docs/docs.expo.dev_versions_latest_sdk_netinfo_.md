# NetInfo
[GitHub](https://docs.expo.dev/versions/latest/sdk/netinfo/<https:/github.com/react-native-community/react-native-netinfo> "View source code of @react-native-community/netinfo on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/netinfo/<https:/www.npmjs.com/package/@react-native-community/netinfo> "View package in npm Registry")
A cross-platform API that provides access to network information.
[GitHub](https://docs.expo.dev/versions/latest/sdk/netinfo/<https:/github.com/react-native-community/react-native-netinfo> "View source code of @react-native-community/netinfo on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/netinfo/<https:/www.npmjs.com/package/@react-native-community/netinfo> "View package in npm Registry")

`@react-native-community/netinfo` allows you to get information about connection type and connection quality.
## Installation[](https://docs.expo.dev/versions/latest/sdk/netinfo/<#installation>)
Terminal
Copy
`- ``npx expo install @react-native-community/netinfo`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/latest/sdk/netinfo/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/latest/sdk/netinfo/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/latest/sdk/netinfo/<https:/github.com/react-native-community/react-native-netinfo#getting-started>) provided by the library's README or documentation.
## API[](https://docs.expo.dev/versions/latest/sdk/netinfo/<#api>)
To import this library, use:
```
import NetInfo from '@react-native-community/netinfo';

```

If you want to grab information about the network connection just once, you can use:
```
NetInfo.fetch().then(state => {
 console.log('Connection type', state.type);
 console.log('Is connected?', state.isConnected);
});

```

Or, if you'd rather subscribe to updates about the network state (which then allows you to run code/perform actions anytime the network state changes) use:
```
const unsubscribe = NetInfo.addEventListener(state => {
 console.log('Connection type', state.type);
 console.log('Is connected?', state.isConnected);
});
// To unsubscribe to these update, just use:
unsubscribe();

```

## Accessing the SSID[](https://docs.expo.dev/versions/latest/sdk/netinfo/<#accessing-the-ssid>)
To access the `ssid` property (available under `state.details.ssid`), there are a few additional configuration steps:
### Android and iOS[](https://docs.expo.dev/versions/latest/sdk/netinfo/<#android-and-ios>)
  * Request location permissions with `Location.requestForegroundPermissionsAsync()`[](https://docs.expo.dev/versions/latest/sdk/netinfo/</versions/latest/sdk/location#locationrequestforegroundpermissionsasync>) or `Location.requestBackgroundPermissionsAsync()`[](https://docs.expo.dev/versions/latest/sdk/netinfo/</versions/latest/sdk/location#locationrequestbackgroundpermissionsasync>).


### iOS only[](https://docs.expo.dev/versions/latest/sdk/netinfo/<#ios-only>)
  * Add the `com.apple.developer.networking.wifi-info` entitlement to your app.json under `ios.entitlements`:
app.json
Copy
```
 "ios": {
  "entitlements": {
   "com.apple.developer.networking.wifi-info": true
  }
 }

```

  * Check the Access Wi-Fi Information box in your app's App Identifier, [which can be found here](https://docs.expo.dev/versions/latest/sdk/netinfo/<https:/developer.apple.com/account/resources/identifiers/list>).
  * Rebuild your app with `eas build --platform ios`[](https://docs.expo.dev/versions/latest/sdk/netinfo/</build/setup#4-run-a-build>) or `npx expo run:ios`[](https://docs.expo.dev/versions/latest/sdk/netinfo/</more/expo-cli#compiling>).


For more information on API and usage, see `react-native-netinfo`[ documentation](https://docs.expo.dev/versions/latest/sdk/netinfo/<https:/github.com/react-native-community/react-native-netinfo#react-native-communitynetinfo>).
