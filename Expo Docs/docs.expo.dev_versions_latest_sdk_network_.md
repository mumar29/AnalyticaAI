# ![Expo Network icon](https://docs.expo.dev/static/images/packages/expo-network.png)Expo Network
[GitHub](https://docs.expo.dev/versions/latest/sdk/network/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-network> "View source code of expo-network on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/network/<https:/www.npmjs.com/package/expo-network> "View package in npm Registry")
A library that provides access to the device's network such as its IP address, MAC address, and airplane mode status.
[GitHub](https://docs.expo.dev/versions/latest/sdk/network/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-network> "View source code of expo-network on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/network/<https:/www.npmjs.com/package/expo-network> "View package in npm Registry")
Android
iOS
tvOS
Web
`expo-network` provides useful information about the device's network such as its IP address, MAC address, and airplane mode status.
## Installation[](https://docs.expo.dev/versions/latest/sdk/network/<#installation>)
Terminal
Copy
`- ``npx expo install expo-network`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/latest/sdk/network/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/latest/sdk/network/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/latest/sdk/network/<https:/github.com/expo/expo/tree/main/packages/expo-network>) as mentioned by the library's README under "Installation in bare React Native projects" section.
## Configuration[](https://docs.expo.dev/versions/latest/sdk/network/<#configuration>)
On Android, this module requires permissions to access the network and Wi-Fi state. The permissions `ACCESS_NETWORK_STATE` and `ACCESS_WIFI_STATE` are added automatically.
## API[](https://docs.expo.dev/versions/latest/sdk/network/<#api>)
```
import * as Network from 'expo-network';

```

## Hooks[](https://docs.expo.dev/versions/latest/sdk/network/<#hooks>)
### `useNetworkState()`[](https://docs.expo.dev/versions/latest/sdk/network/<#usenetworkstate>)
Android
iOS
tvOS
Web
Returns the current network state of the device. This method initiates a listener for network state changes and cleans up before unmounting.
Returns:
`NetworkState[](https://docs.expo.dev/versions/latest/sdk/network/<#networkstate>)`
The current network state of the device, including connectivity and type.
Example
```
const networkState = useNetworkState();
console.log(`Current network type: ${networkState.type}`);

```

## Methods[](https://docs.expo.dev/versions/latest/sdk/network/<#methods>)
### `Network.getIpAddressAsync()`[](https://docs.expo.dev/versions/latest/sdk/network/<#networkgetipaddressasync>)
Android
iOS
tvOS
Web
Gets the device's current IPv4 address. Returns `0.0.0.0` if the IP address could not be retrieved.
On web, this method uses the third-party `ipify service`[](https://docs.expo.dev/versions/latest/sdk/network/<https:/www.ipify.org/>) to get the public IP address of the current device.
Returns:
`Promise[](https://docs.expo.dev/versions/latest/sdk/network/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<string>`
A `Promise` that fulfils with a `string` of the current IP address of the device's main network interface. Can only be IPv4 address.
Example
```
await Network.getIpAddressAsync();
// "92.168.32.44"

```

### `Network.getNetworkStateAsync()`[](https://docs.expo.dev/versions/latest/sdk/network/<#networkgetnetworkstateasync>)
Android
iOS
tvOS
Web
Gets the device's current network connection state.
On web, `navigator.connection.type` is not available on browsers. So if there is an active network connection, the field `type` returns `NetworkStateType.UNKNOWN`. Otherwise, it returns `NetworkStateType.NONE`.
Returns:
`Promise[](https://docs.expo.dev/versions/latest/sdk/network/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<NetworkState[](https://docs.expo.dev/versions/latest/sdk/network/<#networkstate>)>`
A `Promise` that fulfils with a `NetworkState` object.
Example
```
await Network.getNetworkStateAsync();
// {
//  type: NetworkStateType.CELLULAR,
//  isConnected: true,
//  isInternetReachable: true,
// }

```

### `Network.isAirplaneModeEnabledAsync()`[](https://docs.expo.dev/versions/latest/sdk/network/<#networkisairplanemodeenabledasync>)
Android
Tells if the device is in airplane mode.
Returns:
`Promise[](https://docs.expo.dev/versions/latest/sdk/network/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<boolean>`
Returns a `Promise` that fulfils with a `boolean` value for whether the device is in airplane mode or not.
Example
```
await Network.isAirplaneModeEnabledAsync();
// false

```

## Event Subscriptions[](https://docs.expo.dev/versions/latest/sdk/network/<#event-subscriptions>)
### `Network.addNetworkStateListener(listener)`[](https://docs.expo.dev/versions/latest/sdk/network/<#networkaddnetworkstatelistenerlistener>)
Android
iOS
tvOS
Web
Parameter| Type| Description  
---|---|---  
listener| `(event: NetworkState[](https://docs.expo.dev/versions/latest/sdk/network/<#networkstate>)) => void`| Callback to execute when the network state changes. The callback is provided with a single argument that is an object containing information about the network state.  
Adds a listener that will fire whenever the network state changes.
Returns:
`EventSubscription`
A subscription object with a remove function to unregister the listener.
Example
```
const subscription = addNetworkStateListener(({ type, isConnected, isInternetReachable }) => {
 console.log(`Network type: ${type}, Connected: ${isConnected}, Internet Reachable: ${isInternetReachable}`);
});

```

## Types[](https://docs.expo.dev/versions/latest/sdk/network/<#types>)
### `NetworkState`[](https://docs.expo.dev/versions/latest/sdk/network/<#networkstate>)
Android
iOS
tvOS
Web
Property| Type| Description  
---|---|---  
isConnected(optional)| `boolean`| If there is an active network connection. Note that this does not mean that internet is reachable. This field is `false` if the type is either `Network.NetworkStateType.NONE` or `Network.NetworkStateType.UNKNOWN`, `true` otherwise.  
isInternetReachable(optional)| `boolean`| If the internet is reachable with the currently active network connection. On Android, this depends on `NetInfo.isConnected()` (API level < 29) or `ConnectivityManager.getActiveNetwork()` (API level >= 29). On iOS, this value will always be the same as `isConnected`.  
type(optional)| `NetworkStateType[](https://docs.expo.dev/versions/latest/sdk/network/<#networkstatetype>)`| A `NetworkStateType`[](https://docs.expo.dev/versions/latest/sdk/network/<#networkstatetype>) enum value that represents the current network connection type.

## Error codes[](https://docs.expo.dev/versions/latest/sdk/network/<#error-codes>)
Code| Description  
---|---  
ERR_NETWORK_IP_ADDRESS| On Android, there may be an unknown Wi-Fi host when trying to access `WifiManager` in `getIpAddressAsync`. On iOS, no network interfaces could be retrieved.  
ERR_NETWORK_UNDEFINED_INTERFACE| An undefined `interfaceName` was passed as an argument in `getMacAddressAsync`.  
ERR_NETWORK_SOCKET_EXCEPTION| An error was encountered in creating or accessing the socket in `getMacAddressAsync`.  
ERR_NETWORK_INVALID_PERMISSION_INTERNET| There are invalid permissions for `android.permission.ACCESS_WIFI_STATE`[](https://docs.expo.dev/versions/latest/sdk/network/<https:/developer.android.com/reference/android/Manifest.permission#ACCESS_WIFI_STATE>) in `getMacAddressAsync`.
