# Screens
[GitHub](https://docs.expo.dev/versions/latest/sdk/screens/<https:/github.com/software-mansion/react-native-screens> "View source code of react-native-screens on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/screens/<https:/www.npmjs.com/package/react-native-screens> "View package in npm Registry")
A library that provides native primitives to represent screens instead of plain React Native View components for better operating system behavior and screen optimizations.
[GitHub](https://docs.expo.dev/versions/latest/sdk/screens/<https:/github.com/software-mansion/react-native-screens> "View source code of react-native-screens on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/screens/<https:/www.npmjs.com/package/react-native-screens> "View package in npm Registry")
Android
iOS
tvOS
Web
`react-native-screens` provides native primitives to represent screens instead of plain `<View>` components To better take advantage of operating system behavior and optimizations around screens. This capability is used by library authors and is unlikely to be used directly by most app developers. It also provides the native components needed for React Navigation's `createNativeStackNavigator`[](https://docs.expo.dev/versions/latest/sdk/screens/<https:/reactnavigation.org/docs/native-stack-navigator>).
> Note: See `react-native-screens`[ issue tracker](https://docs.expo.dev/versions/latest/sdk/screens/<https:/github.com/software-mansion/react-native-screens/issues>) if you encounter any problems.
## Installation[](https://docs.expo.dev/versions/latest/sdk/screens/<#installation>)
Terminal
Copy
`- ``npx expo install react-native-screens`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/latest/sdk/screens/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/latest/sdk/screens/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/latest/sdk/screens/<https:/github.com/software-mansion/react-native-screens#installation>) provided by the library's README or documentation.
## API[](https://docs.expo.dev/versions/latest/sdk/screens/<#api>)
The complete API reference and documentation are available in the `react-native-screens`[ README](https://docs.expo.dev/versions/latest/sdk/screens/<https:/github.com/software-mansion/react-native-screens>).
To use the native stack navigator if you are using React Navigation, see `createNativeStackNavigator`[ documentation](https://docs.expo.dev/versions/latest/sdk/screens/<https:/reactnavigation.org/docs/native-stack-navigator>).
