# Skia
[GitHub](https://docs.expo.dev/versions/latest/sdk/skia/<https:/github.com/shopify/react-native-skia> "View source code of @shopify/react-native-skia on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/skia/<https:/www.npmjs.com/package/@shopify/react-native-skia> "View package in npm Registry")
A React Native library for creating graphics using Skia.
[GitHub](https://docs.expo.dev/versions/latest/sdk/skia/<https:/github.com/shopify/react-native-skia> "View source code of @shopify/react-native-skia on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/skia/<https:/www.npmjs.com/package/@shopify/react-native-skia> "View package in npm Registry")
Android
iOS
Web
> This library is listed in the Expo SDK reference because it is included in [Expo Go](https://docs.expo.dev/versions/latest/sdk/skia/<https:/expo.dev/go>). You may use any library of your choice with [development builds](https://docs.expo.dev/versions/latest/sdk/skia/</develop/development-builds/introduction>).
`@shopify/react-native-skia` brings the Skia Graphics Library to React Native. Skia serves as the graphics engine for Google Chrome and Chrome OS, Android, Flutter, Mozilla Firefox and Firefox OS, and many other products.
## Installation[](https://docs.expo.dev/versions/latest/sdk/skia/<#installation>)
Terminal
Copy
`- ``npx expo install @shopify/react-native-skia`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/latest/sdk/skia/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/latest/sdk/skia/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/latest/sdk/skia/<https:/shopify.github.io/react-native-skia/docs/getting-started/installation/>) provided by the library's README or documentation.
> Additional setup required for web: If you want to use Skia on web, you will need to follow [web installation instructions](https://docs.expo.dev/versions/latest/sdk/skia/<https:/shopify.github.io/react-native-skia/docs/getting-started/web/#expo>) to load CanvasKit.
