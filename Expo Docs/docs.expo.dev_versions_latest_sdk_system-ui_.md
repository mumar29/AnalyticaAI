# Expo SystemUI
[GitHub](https://docs.expo.dev/versions/latest/sdk/system-ui/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-system-ui> "View source code of expo-system-ui on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/system-ui/<https:/www.npmjs.com/package/expo-system-ui> "View package in npm Registry")
A library that allows interacting with system UI elements.
[GitHub](https://docs.expo.dev/versions/latest/sdk/system-ui/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-system-ui> "View source code of expo-system-ui on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/system-ui/<https:/www.npmjs.com/package/expo-system-ui> "View package in npm Registry")
Android
iOS
Web
`expo-system-ui` enables you to interact with UI elements that fall outside of the React tree. Specifically the root view background color, and locking the user interface style globally on Android.
## Installation[](https://docs.expo.dev/versions/latest/sdk/system-ui/<#installation>)
Terminal
Copy
`- ``npx expo install expo-system-ui`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/latest/sdk/system-ui/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/latest/sdk/system-ui/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/latest/sdk/system-ui/<https:/github.com/expo/expo/tree/main/packages/expo-system-ui>) as mentioned by the library's README under "Installation in bare React Native projects" section.
## API[](https://docs.expo.dev/versions/latest/sdk/system-ui/<#api>)
```
import * as SystemUI from 'expo-system-ui';

```

## Methods[](https://docs.expo.dev/versions/latest/sdk/system-ui/<#methods>)
### `SystemUI.getBackgroundColorAsync()`[](https://docs.expo.dev/versions/latest/sdk/system-ui/<#systemuigetbackgroundcolorasync>)
Android
iOS
Web
Gets the root view background color.
Returns:
`Promise[](https://docs.expo.dev/versions/latest/sdk/system-ui/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<ColorValue | null>`
Current root view background color in hex format. Returns `null` if the background color is not set.
Example
```
const color = await SystemUI.getBackgroundColorAsync();

```

### `SystemUI.setBackgroundColorAsync(color)`[](https://docs.expo.dev/versions/latest/sdk/system-ui/<#systemuisetbackgroundcolorasynccolor>)
Android
iOS
Web
Parameter| Type| Description  
---|---|---  
color| `null | ColorValue`| Any valid [CSS 3 (SVG) color](https://docs.expo.dev/versions/latest/sdk/system-ui/<http:/www.w3.org/TR/css3-color/#svg-color>).  
Changes the root view background color. Call this function in the root file outside of you component.
Returns:
`Promise[](https://docs.expo.dev/versions/latest/sdk/system-ui/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<void>`
Example
```
SystemUI.setBackgroundColorAsync("black");

```
