# ViewPager
[GitHub](https://docs.expo.dev/versions/latest/sdk/view-pager/<https:/github.com/callstack/react-native-pager-view> "View source code of react-native-pager-view on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/view-pager/<https:/www.npmjs.com/package/react-native-pager-view> "View package in npm Registry")
A component library that provides a carousel-like view to swipe through pages of content.
[GitHub](https://docs.expo.dev/versions/latest/sdk/view-pager/<https:/github.com/callstack/react-native-pager-view> "View source code of react-native-pager-view on GitHub")[npm](https://docs.expo.dev/versions/latest/sdk/view-pager/<https:/www.npmjs.com/package/react-native-pager-view> "View package in npm Registry")
Android
iOS
> This library is listed in the Expo SDK reference because it is included in [Expo Go](https://docs.expo.dev/versions/latest/sdk/view-pager/<https:/expo.dev/go>). You may use any library of your choice with [development builds](https://docs.expo.dev/versions/latest/sdk/view-pager/</develop/development-builds/introduction>).
`react-native-pager-view` exposes a component that provides the layout and gestures to scroll between pages of content, like a carousel.
## Installation[](https://docs.expo.dev/versions/latest/sdk/view-pager/<#installation>)
Terminal
Copy
`- ``npx expo install react-native-pager-view`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/latest/sdk/view-pager/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/latest/sdk/view-pager/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/latest/sdk/view-pager/<https:/github.com/callstack/react-native-pager-view#linking>) provided by the library's README or documentation.
## Usage[](https://docs.expo.dev/versions/latest/sdk/view-pager/<#usage>)
See full documentation at [callstack/react-native-pager-view](https://docs.expo.dev/versions/latest/sdk/view-pager/<https:/github.com/callstack/react-native-pager-view>).
## Example[](https://docs.expo.dev/versions/latest/sdk/view-pager/<#example>)
App.js
Copy
```
import { StyleSheet, View, Text } from 'react-native';
import PagerView from 'react-native-pager-view';
export default function MyPager() {
 return (
  <View style={styles.container}><PagerView style={styles.container} initialPage={0}><View style={styles.page} key="1"><Text>First page</Text><Text>Swipe ➡️</Text></View><View style={styles.page} key="2"><Text>Second page</Text></View><View style={styles.page} key="3"><Text>Third page</Text></View></PagerView></View>
 );
}
const styles = StyleSheet.create({
 container: {
  flex: 1,
 },
 page: {
  justifyContent: 'center',
  alignItems: 'center',
 },
});
```
