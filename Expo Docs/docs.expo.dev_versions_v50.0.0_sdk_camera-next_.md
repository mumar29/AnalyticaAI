# ![Expo Camera \(Next\) icon](https://docs.expo.dev/static/images/packages/expo-camera.png)Expo Camera (Next)
[GitHub](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/<https:/github.com/expo/expo/tree/main/packages/expo-camera> "View source code of expo-camera on GitHub")[npm](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/<https:/www.npmjs.com/package/expo-camera> "View package in npm Registry")
A React component that renders a preview for the device's front or back camera.
[GitHub](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/<https:/github.com/expo/expo/tree/main/packages/expo-camera> "View source code of expo-camera on GitHub")[npm](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/<https:/www.npmjs.com/package/expo-camera> "View package in npm Registry")
> This page documents an upcoming version of the Camera library. To try it, switch to `expo-camera/next` imports in your code.
> What are Next (`/next`) libraries[](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/<#what-are-next-next-libraries>)
> Next libraries are pre-release versions of SDK libraries. We provide them to get feedback from the community and test new features before their stable release. If you encounter any issue, we encourage reporting on the [Expo](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/<https:/github.com/expo/expo/issues/new?assignees=&labels=needs+validation&projects=&template=bug_report.yml>) GitHub repository.
`expo-camera` provides a React component that renders a preview of the device's front or back camera. The camera's parameters such as zoom, torch, and flash mode are adjustable. Using `CameraView`, you can take photos and record videos that are saved to the app's cache. The component is also capable of detecting bar codes appearing in the preview. Run the [example](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/</versions/v50.0.0/sdk/camera-next#usage>) on your device to see all these features working together.

## Usage[](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/<#usage>)
> Only one Camera preview can be active at any given time. If you have multiple screens in your app, you should unmount `Camera` components whenever a screen is unfocused.
```
import { CameraView, useCameraPermissions } from 'expo-camera/next';
import { useState } from 'react';
import { Button, StyleSheet, Text, TouchableOpacity, View } from 'react-native';
export default function App() {
 const [facing, setFacing] = useState('back');
 const [permission, requestPermission] = useCameraPermissions();
 if (!permission) {
  // Camera permissions are still loading
  return <View />;
 }
 if (!permission.granted) {
  // Camera permissions are not granted yet
  return (
   <View style={styles.container}><Text style={{ textAlign: 'center' }}>We need your permission to show the camera</Text><Button onPress={requestPermission} title="grant permission" /></View>
  );
 }
 function toggleCameraFacing() {
  setFacing(current => (current === 'back' ? 'front' : 'back'));
 }
 return (
  <View style={styles.container}><CameraView style={styles.camera} facing={facing}><View style={styles.buttonContainer}><TouchableOpacity style={styles.button} onPress={toggleCameraFacing}><Text style={styles.text}>Flip Camera</Text></TouchableOpacity></View></CameraView></View>
 );
}
const styles = StyleSheet.create({
 container: {
  flex: 1,
  justifyContent: 'center',
 },
 camera: {
  flex: 1,
 },
 buttonContainer: {
  flex: 1,
  flexDirection: 'row',
  backgroundColor: 'transparent',
  margin: 64,
 },
 button: {
  flex: 1,
  alignSelf: 'flex-end',
  alignItems: 'center',
 },
 text: {
  fontSize: 24,
  fontWeight: 'bold',
  color: 'white',
 },
});
```

## Web support[](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/<#web-support>)
Most browsers support a version of web camera functionality, you can check out the [web camera browser support here](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/<https:/caniuse.com/#feat=stream>). Image URIs are always returned as base64 strings because local file system paths are unavailable in the browser.
### Chrome `iframe` usage[](https://docs.expo.dev/versions/v50.0.0/sdk/camera-next/<#chrome-iframe-usage>)
When using Chrome versions 64+, if you try to use a web camera in a cross-origin iframe nothing will render. To add support for cameras in your iframe simply add the attribute `allow="microphone; camera;"` to the iframe element:
```
<iframe src="..." allow="microphone; camera;">
 <!-- <CameraView /> -->
</iframe>

```
