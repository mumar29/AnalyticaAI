# Expo Constants
[GitHub](https://docs.expo.dev/versions/v50.0.0/sdk/constants/<https:/github.com/expo/expo/tree/sdk-50/packages/expo-constants> "View source code of expo-constants on GitHub")[npm](https://docs.expo.dev/versions/v50.0.0/sdk/constants/<https:/www.npmjs.com/package/expo-constants> "View package in npm Registry")
An API that provides system information that remains constant throughout the lifetime of your app's installation.
[GitHub](https://docs.expo.dev/versions/v50.0.0/sdk/constants/<https:/github.com/expo/expo/tree/sdk-50/packages/expo-constants> "View source code of expo-constants on GitHub")[npm](https://docs.expo.dev/versions/v50.0.0/sdk/constants/<https:/www.npmjs.com/package/expo-constants> "View package in npm Registry")
`expo-constants` provides system information that remains constant throughout the lifetime of your app's installation.

## Installation[](https://docs.expo.dev/versions/v50.0.0/sdk/constants/<#installation>)
Terminal
Copy
`- ``npx expo install expo-constants`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/v50.0.0/sdk/constants/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/v50.0.0/sdk/constants/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/v50.0.0/sdk/constants/<https:/github.com/expo/expo/tree/main/packages/expo-constants>) as mentioned by the library's README under "Installation in bare React Native projects" section.

versionCode| `number`|
