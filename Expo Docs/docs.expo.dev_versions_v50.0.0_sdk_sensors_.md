# ![Expo Sensors icon](https://docs.expo.dev/static/images/packages/expo-sensors.png)Expo Sensors
[GitHub](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<https:/github.com/expo/expo/tree/sdk-50/packages/expo-sensors> "View source code of expo-sensors on GitHub")[npm](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<https:/www.npmjs.com/package/expo-sensors> "View package in npm Registry")
A library that provides access to a device's accelerometer, barometer, motion, gyroscope, light, magnetometer, and pedometer.
[GitHub](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<https:/github.com/expo/expo/tree/sdk-50/packages/expo-sensors> "View source code of expo-sensors on GitHub")[npm](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<https:/www.npmjs.com/package/expo-sensors> "View package in npm Registry")
`expo-sensors` provide various APIs for accessing device sensors to measure motion, orientation, pressure, magnetic fields, ambient light, and step count.

## Installation[](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<#installation>)
Terminal
Copy
`- ``npx expo install expo-sensors`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<https:/github.com/expo/expo/tree/main/packages/expo-sensors>) as mentioned by the library's README under "Installation in bare React Native projects" section.
## API[](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<#api>)
```
import * as Sensors from 'expo-sensors';
// OR
import {
 Accelerometer,
 Barometer,
 DeviceMotion,
 Gyroscope,
 LightSensor,
 Magnetometer,
 MagnetometerUncalibrated,
 Pedometer,
} from 'expo-sensors';

```

## Permissions[](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<#permissions>)
### Android[](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<#android>)
Starting in Android 12 (API level 31), the system has a 200Hz limit for each sensor updates.
If you need an update interval of less than 200Hz, you must add the following permissions to your app.json inside the `expo.android.permissions`[](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/</versions/v50.0.0/config/app#permissions>) array.
Android Permission| Description  
---|---  
`HIGH_SAMPLING_RATE_SENSORS`[](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<#permission-high_sampling_rate_sensors>)| Allows an app to access sensor data with a sampling rate greater than 200 Hz.  
Are you using this library in a bare React Native app?[](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<#are-you-using-this-library-in-a>)
Learn how to configure the native projects in the [installation instructions in the `expo-sensors` repository](https://docs.expo.dev/versions/v50.0.0/sdk/sensors/<https:/github.com/expo/expo/tree/main/packages/expo-sensors#installation-in-bare-react-native-projects>).
