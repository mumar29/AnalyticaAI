# ![Expo Brightness icon](https://docs.expo.dev/static/images/packages/expo-brightness.png)Expo Brightness
[GitHub](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/github.com/expo/expo/tree/sdk-51/packages/expo-brightness> "View source code of expo-brightness on GitHub")[npm](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/www.npmjs.com/package/expo-brightness> "View package in npm Registry")
A library that provides access to an API for getting and setting the screen brightness.
[GitHub](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/github.com/expo/expo/tree/sdk-51/packages/expo-brightness> "View source code of expo-brightness on GitHub")[npm](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/www.npmjs.com/package/expo-brightness> "View package in npm Registry")
Android
iOS
An API to get and set screen brightness.
On Android, there is a global system-wide brightness setting, and each app has its own brightness setting that can optionally override the global setting. It is possible to set either of these values with this API. On iOS, the system brightness setting cannot be changed programmatically; instead, any changes to the screen brightness will persist until the device is locked or powered off.

## Hooks[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#hooks>)
### `usePermissions(options)`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#usepermissionsoptions>)
Parameter| Type  
---|---  
options(optional)| `PermissionHookOptions[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#permissionhookoptions>)<object>`  
Check or request permissions to modify the system brightness. This uses both `requestPermissionAsync` and `getPermissionsAsync` to interact with the permissions.
Returns:
`[null | PermissionResponse[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#permissionresponse>), RequestPermissionMethod<PermissionResponse[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#permissionresponse>)>, GetPermissionMethod<PermissionResponse[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#permissionresponse>)>]`
Example
```
const [permissionResponse, requestPermission] = Brightness.usePermissions();

```

## Methods[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#methods>)
### `Brightness.getBrightnessAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessgetbrightnessasync>)
Gets the current brightness level of the device's main screen.
Returns:
`Promise[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<number>`
A `Promise` that fulfils with a number between `0` and `1`, inclusive, representing the current screen brightness.
### `Brightness.getPermissionsAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessgetpermissionsasync>)
Checks user's permissions for accessing system brightness.
Returns:
`Promise[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<PermissionResponse[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#permissionresponse>)>`
A promise that fulfils with an object of type [PermissionResponse](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#permissionrespons>).
### `Brightness.getSystemBrightnessAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessgetsystembrightnessasync>)
Only for: 
Android
Gets the global system screen brightness.
Returns:
`Promise[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<number>`
A `Promise` that is resolved with a number between `0` and `1`, inclusive, representing the current system screen brightness.
### `Brightness.getSystemBrightnessModeAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessgetsystembrightnessmodeasync>)
Only for: 
Android
Gets the system brightness mode (e.g. whether or not the OS will automatically adjust the screen brightness depending on ambient light).
Returns:
`Promise[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<BrightnessMode[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessmode>)>`
A `Promise` that fulfils with a `BrightnessMode`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessmode>). Requires `SYSTEM_BRIGHTNESS` permissions.
### `Brightness.isAvailableAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessisavailableasync>)
Returns whether the Brightness API is enabled on the current device. This does not check the app permissions.
Returns:
`Promise[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<boolean>`
Async `boolean`, indicating whether the Brightness API is available on the current device. Currently this resolves `true` on iOS and Android only.
### `Brightness.isUsingSystemBrightnessAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessisusingsystembrightnessasync>)
Only for: 
Android
Returns a boolean specifying whether or not the current activity is using the system-wide brightness value.
Returns:
`Promise[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<boolean>`
A `Promise` that fulfils with `true` when the current activity is using the system-wide brightness value, and `false` otherwise.
### `Brightness.requestPermissionsAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessrequestpermissionsasync>)
Asks the user to grant permissions for accessing system brightness.
Returns:
`Promise[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<PermissionResponse[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#permissionresponse>)>`
A promise that fulfils with an object of type [PermissionResponse](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#permissionrespons>).
### `Brightness.restoreSystemBrightnessAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessrestoresystembrightnessasync>)
Only for: 
Android
Resets the brightness setting of the current activity to use the system-wide brightness value rather than overriding it.

### `BrightnessMode`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#brightnessmode>)
#### `UNKNOWN`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#unknown>)
`BrightnessMode.UNKNOWN ＝ 0`
Means that the current brightness mode cannot be determined.
#### `AUTOMATIC`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#automatic>)
`BrightnessMode.AUTOMATIC ＝ 1`
Mode in which the device OS will automatically adjust the screen brightness depending on the ambient light.
#### `MANUAL`[](https://docs.expo.dev/versions/v51.0.0/sdk/brightness/<#manual>)
`BrightnessMode.MANUAL ＝ 2`
Mode in which the screen brightness will remain constant and will not be adjusted by the OS.
