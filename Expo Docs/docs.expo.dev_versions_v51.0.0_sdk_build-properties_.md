# Expo BuildProperties
[GitHub](https://docs.expo.dev/versions/v51.0.0/sdk/build-properties/<https:/github.com/expo/expo/tree/sdk-51/packages/expo-build-properties> "View source code of expo-build-properties on GitHub")[npm](https://docs.expo.dev/versions/v51.0.0/sdk/build-properties/<https:/www.npmjs.com/package/expo-build-properties> "View package in npm Registry")
A config plugin that allows customizing native build properties during prebuild.
[GitHub](https://docs.expo.dev/versions/v51.0.0/sdk/build-properties/<https:/github.com/expo/expo/tree/sdk-51/packages/expo-build-properties> "View source code of expo-build-properties on GitHub")[npm](https://docs.expo.dev/versions/v51.0.0/sdk/build-properties/<https:/www.npmjs.com/package/expo-build-properties> "View package in npm Registry")
Android
iOS
tvOS
`expo-build-properties` is a [config plugin](https://docs.expo.dev/versions/v51.0.0/sdk/build-properties/</config-plugins/introduction>) configuring the native build properties of your android/gradle.properties and ios/Podfile.properties.json directories during [Prebuild](https://docs.expo.dev/versions/v51.0.0/sdk/build-properties/</workflow/prebuild>).
> This config plugin configures how [Prebuild command](https://docs.expo.dev/versions/v51.0.0/sdk/build-properties/</workflow/prebuild>) generates the native android and ios directories and therefore cannot be used with projects that don't run `npx expo prebuild` (bare projects).

app.json
app.config.js
app.json
Copy
```
{
 "expo": {
  "plugins": [
   [
    "expo-build-properties",
    {
     "android": {
      "compileSdkVersion": 34,
      "targetSdkVersion": 34,
      "buildToolsVersion": "34.0.0"
     },
     "ios": {
      "deploymentTarget": "13.4"
     }
    }
   ]
  ]
 }
}

```

app.config.js
Copy
```
export default {
 expo: {
  plugins: [
   [
    'expo-build-properties',
    {
     android: {
      compileSdkVersion: 34,
      targetSdkVersion: 34,
      buildToolsVersion: '34.0.0',
     },
     ios: {
      deploymentTarget: '13.4',
     },
    },
   ],
  ],
 },
};

```

}

```

  maven {

    password = "baz"
   }
   authentication {
    basic(BasicAuthentication)
   }
  }
 }
}

```
