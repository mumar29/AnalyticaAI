# ![Expo Network icon](https://docs.expo.dev/static/images/packages/expo-network.png)Expo Network
[GitHub](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/github.com/expo/expo/tree/sdk-51/packages/expo-network> "View source code of expo-network on GitHub")[npm](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/www.npmjs.com/package/expo-network> "View package in npm Registry")
A library that provides access to the device's network such as its IP address, MAC address, and airplane mode status.
[GitHub](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/github.com/expo/expo/tree/sdk-51/packages/expo-network> "View source code of expo-network on GitHub")[npm](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/www.npmjs.com/package/expo-network> "View package in npm Registry")
Android
iOS
tvOS
Web
`expo-network` provides useful information about the device's network such as its IP address, MAC address, and airplane mode status.
## Installation[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#installation>)
Terminal
Copy
`- ``npx expo install expo-network`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/v51.0.0/sdk/network/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/v51.0.0/sdk/network/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/github.com/expo/expo/tree/main/packages/expo-network>) as mentioned by the library's README under "Installation in bare React Native projects" section.
## Configuration[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#configuration>)
On Android, this module requires permissions to access the network and Wi-Fi state. The permissions `ACCESS_NETWORK_STATE` and `ACCESS_WIFI_STATE` are added automatically.
## API[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#api>)
```
import * as Network from 'expo-network';

```

## Methods[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#methods>)
### `Network.getIpAddressAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#networkgetipaddressasync>)
Gets the device's current IPv4 address. Returns `0.0.0.0` if the IP address could not be retrieved.
On web, this method uses the third-party `ipify service`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/www.ipify.org/>) to get the public IP address of the current device.
Returns:
`Promise[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<string>`
A `Promise` that fulfils with a `string` of the current IP address of the device's main network interface. Can only be IPv4 address.
Example
```
await Network.getIpAddressAsync();
// "92.168.32.44"

```

### `Network.getNetworkStateAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#networkgetnetworkstateasync>)
Gets the device's current network connection state.
On web, `navigator.connection.type` is not available on browsers. So if there is an active network connection, the field `type` returns `NetworkStateType.UNKNOWN`. Otherwise, it returns `NetworkStateType.NONE`.
Returns:
`Promise[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<NetworkState[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#networkstate>)>`
A `Promise` that fulfils with a `NetworkState` object.
Example
```
await Network.getNetworkStateAsync();
// {
//  type: NetworkStateType.CELLULAR,
//  isConnected: true,
//  isInternetReachable: true,
// }

```

### `Network.isAirplaneModeEnabledAsync()`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#networkisairplanemodeenabledasync>)
Only for: 
Android
Tells if the device is in airplane mode.
Returns:
`Promise[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<boolean>`
Returns a `Promise` that fulfils with a `boolean` value for whether the device is in airplane mode or not.
Example
```
await Network.isAirplaneModeEnabledAsync();
// false

```

## Types[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#types>)
### `NetworkState`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#networkstate>)
Property| Type| Description  
---|---|---  
isConnected(optional)| `boolean`| If there is an active network connection. Note that this does not mean that internet is reachable. This field is `false` if the type is either `Network.NetworkStateType.NONE` or `Network.NetworkStateType.UNKNOWN`, `true` otherwise.  
isInternetReachable(optional)| `boolean`| If the internet is reachable with the currently active network connection. On Android, this depends on `NetInfo.isConnected()` (API level < 29) or `ConnectivityManager.getActiveNetwork()` (API level >= 29). On iOS, this value will always be the same as `isConnected`.  
type(optional)| `NetworkStateType[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#networkstatetype>)`| A `NetworkStateType`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#networkstatetype>) enum value that represents the current network connection type.  
## Enums[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#enums>)
### `NetworkStateType`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#networkstatetype>)
An enum of the different types of devices supported by Expo.
#### `BLUETOOTH`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#bluetooth>)
`NetworkStateType.BLUETOOTH ＝ "BLUETOOTH"`
Active network connection over Bluetooth.
#### `CELLULAR`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#cellular>)
`NetworkStateType.CELLULAR ＝ "CELLULAR"`
Active network connection over mobile data or `DUN-specific`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/developer.android.com/reference/android/net/ConnectivityManager#TYPE_MOBILE_DUN>) mobile connection when setting an upstream connection for tethering.
#### `ETHERNET`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#ethernet>)
`NetworkStateType.ETHERNET ＝ "ETHERNET"`
Active network connection over Ethernet.
#### `NONE`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#none>)
`NetworkStateType.NONE ＝ "NONE"`
No active network connection detected.
#### `OTHER`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#other>)
`NetworkStateType.OTHER ＝ "OTHER"`
Active network connection over other network connection types.
#### `UNKNOWN`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#unknown>)
`NetworkStateType.UNKNOWN ＝ "UNKNOWN"`
The connection type could not be determined.
#### `VPN`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#vpn>)
`NetworkStateType.VPN ＝ "VPN"`
Active network connection over VPN.
#### `WIFI`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#wifi>)
`NetworkStateType.WIFI ＝ "WIFI"`
Active network connection over WiFi.
#### `WIMAX`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#wimax>)
`NetworkStateType.WIMAX ＝ "WIMAX"`
Active network connection over Wimax.
## Error codes[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<#error-codes>)
Code| Description  
---|---  
ERR_NETWORK_IP_ADDRESS| On Android, there may be an unknown Wi-Fi host when trying to access `WifiManager` in `getIpAddressAsync`. On iOS, no network interfaces could be retrieved.  
ERR_NETWORK_UNDEFINED_INTERFACE| An undefined `interfaceName` was passed as an argument in `getMacAddressAsync`.  
ERR_NETWORK_SOCKET_EXCEPTION| An error was encountered in creating or accessing the socket in `getMacAddressAsync`.  
ERR_NETWORK_INVALID_PERMISSION_INTERNET| There are invalid permissions for `android.permission.ACCESS_WIFI_STATE`[](https://docs.expo.dev/versions/v51.0.0/sdk/network/<https:/developer.android.com/reference/android/Manifest.permission#ACCESS_WIFI_STATE>) in `getMacAddressAsync`.
