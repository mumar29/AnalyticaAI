# Stripe
[GitHub](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/github.com/stripe/stripe-react-native> "View source code of @stripe/stripe-react-native on GitHub")[npm](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/www.npmjs.com/package/@stripe/stripe-react-native> "View package in npm Registry")
A library that provides access to native APIs for integrating Stripe payments.
[GitHub](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/github.com/stripe/stripe-react-native> "View source code of @stripe/stripe-react-native on GitHub")[npm](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/www.npmjs.com/package/@stripe/stripe-react-native> "View package in npm Registry")
Android
iOS
Expo includes support for `@stripe/stripe-react-native`[](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/github.com/stripe/stripe-react-native>), which allows you to build delightful payment experiences in your native Android and iOS apps using React Native and Expo. This library provides powerful and customizable UI screens and elements that can be used out-of-the-box to collect your users' payment details.
> Migrating from Expo's `expo-payments-stripe` module? [Learn more about how to transition to the new `@stripe/stripe-react-native` library](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/github.com/expo/fyi/blob/main/payments-migration-guide.md#how-to-migrate-from-expo-payments-stripe-to-the-new-stripestripe-react-native-library>).
## Installation[](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<#installation>)
Each Expo SDK version requires a specific `@stripe/stripe-react-native` version. See the [Stripe CHANGELOG](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/github.com/stripe/stripe-react-native/blob/master/CHANGELOG.md>) for a mapping of versions. To automatically install the correct version for your Expo SDK version, run:
Terminal
Copy
`- ``npx expo install @stripe/stripe-react-native`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/github.com/stripe/stripe-react-native>) provided by the library's README or documentation.
### Config plugin setup (optional)[](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<#config-plugin-setup-optional>)
If you're using EAS Build, you can do most of your Stripe setup using the `@stripe/stripe-react-native` [config plugin](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/</config-plugins/introduction>). To set up, just add the config plugin to the `plugins` array of your app.json or app.config.js as shown below, then rebuild the app.
app.json
Copy
```
{
 "expo": {
  %%placeholder-start%%... %%placeholder-end%%
  "plugins": [
   [
    "@stripe/stripe-react-native",
    {
     "merchantIdentifier": string | string [],
     "enableGooglePay": boolean
    }
   ]
  ],
 }
}

```

  * merchantIdentifier: iOS only. This is the [Apple merchant ID obtained here](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/stripe.com/docs/apple-pay?platform=react-native>). Otherwise, Apple Pay will not work as expected. If you have multiple merchantIdentifiers, you can set them in an array.
  * enableGooglePay: Android only. Boolean indicating whether or not Google Pay is enabled. Defaults to `false`.

### Common issues[](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<#common-issues>)
#### Browser pop-ups are not redirecting back to my app[](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<#browser-pop-ups-are-not-redirecting-back-to-my-app>)
If you're relying on redirects, you'll need to pass in a `urlScheme` to `initStripe`. To make sure you always use the proper `urlScheme`, pass in:
```
import * as Linking from 'expo-linking';
import Constants from 'expo-constants';
urlScheme:
 Constants.appOwnership === 'expo'
  ? Linking.createURL('/--/')
  : Linking.createURL(''),

```

`Linking.createURL()`[](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/</versions/v51.0.0/sdk/linking#createurloptions>) will ensure you're using the proper scheme, whether you're running in Expo Go or your production app. `'/--/'` is necessary in Expo Go because it indicates that the substring after it corresponds to the deep link path, and is not part of the path to the app itself.
## Limitations[](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<#limitations>)
### Google Pay[](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<#google-pay>)
Google Pay is not supported in [Expo Go](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/expo.dev/go>). To use Google Pay, you must create a [development build](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/</develop/development-builds/create-a-build>). This can be done with [EAS Build](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/</build/introduction>), or locally by running `npx expo run:android`.
### Apple Pay[](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<#apple-pay>)
Apple Pay is not supported in [Expo Go](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/<https:/expo.dev/go>). To use Apple Pay, you must create a [development build](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/</develop/development-builds/create-a-build>). This can be done with [EAS Build](https://docs.expo.dev/versions/v51.0.0/sdk/stripe/</build/introduction>), or locally by running `npx expo run:ios`.
