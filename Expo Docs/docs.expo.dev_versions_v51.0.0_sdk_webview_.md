# React Native WebView
[GitHub](https://docs.expo.dev/versions/v51.0.0/sdk/webview/<https:/github.com/react-native-webview/react-native-webview> "View source code of react-native-webview on GitHub")[npm](https://docs.expo.dev/versions/v51.0.0/sdk/webview/<https:/www.npmjs.com/package/react-native-webview> "View package in npm Registry")
A library that provides a WebView component.
[GitHub](https://docs.expo.dev/versions/v51.0.0/sdk/webview/<https:/github.com/react-native-webview/react-native-webview> "View source code of react-native-webview on GitHub")[npm](https://docs.expo.dev/versions/v51.0.0/sdk/webview/<https:/www.npmjs.com/package/react-native-webview> "View package in npm Registry")

`react-native-webview` provides a `WebView` component that renders web content in a native view.
## Installation[](https://docs.expo.dev/versions/v51.0.0/sdk/webview/<#installation>)
Terminal
Copy
`- ``npx expo install react-native-webview`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/v51.0.0/sdk/webview/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/v51.0.0/sdk/webview/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/v51.0.0/sdk/webview/<https:/github.com/react-native-webview/react-native-webview/blob/master/docs/Getting-Started.md#react-native-webview-getting-started-guide>) provided by the library's README or documentation.
## Usage[](https://docs.expo.dev/versions/v51.0.0/sdk/webview/<#usage>)
You should refer to the `react-native-webview`[ documentation](https://docs.expo.dev/versions/v51.0.0/sdk/webview/<https:/github.com/react-native-webview/react-native-webview/blob/master/docs/Guide.md#react-native-webview-guide>) for more information on the API and its usage. The following example (courtesy of that repository) is a quick way to get up and running!
Basic Webview usage
Copy
Open in Snack
```
import { WebView } from 'react-native-webview';
import Constants from 'expo-constants';
import { StyleSheet } from 'react-native';
export default function App() {
 return (
  <WebView
   style={styles.container}
   source={{ uri: 'https://expo.dev' }}
  />
 );
}
const styles = StyleSheet.create({
 container: {
  flex: 1,
  marginTop: Constants.statusBarHeight,
 },
});
```

```
import { WebView } from 'react-native-webview';
import Constants from 'expo-constants';
import { StyleSheet } from 'react-native';
export default function App() {
 return (
  <WebView
   style={styles.container}
   originWhitelist={['*']}
   source={{ html: '<h1><center>Hello world</center></h1>' }}
  />
```
