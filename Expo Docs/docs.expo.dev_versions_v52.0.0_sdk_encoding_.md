# Encoding
[GitHub](https://docs.expo.dev/versions/v52.0.0/sdk/encoding/<https:/github.com/expo/expo/tree/sdk-52/packages/expo> "View source code of expo on GitHub")[npm](https://docs.expo.dev/versions/v52.0.0/sdk/encoding/<https:/www.npmjs.com/package/expo> "View package in npm Registry")
Standard TextEncoder and TextDecoder APIs available on all Expo-supported platforms.

The standard URL API is available on all Expo-supported platforms.
## Installation[](https://docs.expo.dev/versions/v52.0.0/sdk/encoding/<#installation>)
This API is part of the `expo` package. Refer to the [browser and server runtime support](https://docs.expo.dev/versions/v52.0.0/sdk/encoding/<https:/caniuse.com/textencoder>) for web and Node.js.
## Usage[](https://docs.expo.dev/versions/v52.0.0/sdk/encoding/<#usage>)
`TextEncoder` and `TextDecoder` are available globally without any need to import them.
```
// [104, 101, 108, 108, 111]
const hello = new TextEncoder().encode('hello');
// "hello"
const text = new TextDecoder().decode(hello);

```

## TextEncoder[](https://docs.expo.dev/versions/v52.0.0/sdk/encoding/<#textencoder>)
The `TextEncoder` API is included in the Hermes engine. See the [source code in TextEncoder.cpp inside the Hermes GitHub repository](https://docs.expo.dev/versions/v52.0.0/sdk/encoding/<https:/github.com/facebook/hermes/blob/9e2bbf8eda15936ee00aee4f8e024ceaa7cd800d/lib/VM/JSLib/TextEncoder.cpp#L1>).
## TextDecoder[](https://docs.expo.dev/versions/v52.0.0/sdk/encoding/<#textdecoder>)
The `TextDecoder` API is not [spec-compliant](https://docs.expo.dev/versions/v52.0.0/sdk/encoding/<https:/encoding.spec.whatwg.org/#textdecoder>) on native platforms. Only the UTF-8 encoding is supported. If you need support for more encodings, use a polyfill like `text-encoding`[](https://docs.expo.dev/versions/v52.0.0/sdk/encoding/<https:/www.npmjs.com/package/text-encoding>).
