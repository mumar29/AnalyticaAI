# Expo IntentLauncher
[GitHub](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-intent-launcher> "View source code of expo-intent-launcher on GitHub")[npm](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<https:/www.npmjs.com/package/expo-intent-launcher> "View package in npm Registry")
A library that provides an API to launch Android intents.
[GitHub](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-intent-launcher> "View source code of expo-intent-launcher on GitHub")[npm](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<https:/www.npmjs.com/package/expo-intent-launcher> "View package in npm Registry")
Android
`expo-intent-launcher` provides a way to launch Android intents. For example, you can use this API to open a specific settings screen.
## Installation[](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<#installation>)
Terminal
Copy
`- ``npx expo install expo-intent-launcher`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<https:/github.com/expo/expo/tree/main/packages/expo-intent-launcher>) as mentioned by the library's README under "Installation in bare React Native projects" section.
## Usage[](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<#usage>)
```
import { startActivityAsync, ActivityAction } from 'expo-intent-launcher';
// Open location settings
startActivityAsync(ActivityAction.LOCATION_SOURCE_SETTINGS);

```

## API[](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<#api>)

import * as IntentLauncher from 'expo-intent-launcher';

### `IntentLauncher.startActivityAsync(activityAction, params)`[](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<#intentlauncherstartactivityasyncactivityaction-params>)
Android
Parameter| Type| Description  
---|---|---  
activityAction| `string`| The action to be performed, e.g. `IntentLauncher.ActivityAction.WIRELESS_SETTINGS`. There are a few pre-defined constants you can use for this parameter. You can find them at [expo-intent-launcher/src/IntentLauncher.ts](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<https:/github.com/expo/expo/blob/main/packages/expo-intent-launcher/src/IntentLauncher.ts>).  
params(optional)| `IntentLauncherParams[](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<#intentlauncherparams>)`| An object of intent parameters.Default:`{}`  
Starts the specified activity. The method will return a promise which resolves when the user returns to the app.
Returns:
`Promise[](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<https:/developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise>)<IntentLauncherResult[](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<#intentlauncherresult>)>`
A promise which fulfils with `IntentLauncherResult` object.

### `IntentLauncherParams`[](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<#intentlauncherparams>)
Android
Property| Type| Description  
---|---|---  
category(optional)| `string`| Category provides more details about the action the intent performs. See [Intent.addCategory](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<https:/developer.android.com/reference/android/content/Intent.html#addCategory\(java.lang.String\)>).  
className(optional)| `string`| Class name of the ComponentName.  
data(optional)| `string`| A URI specifying the data that the intent should operate upon. (_Note:_ Android requires the URI scheme to be lowercase, unlike the formal RFC.)  
extra(optional)| `Record<string, any>`| A map specifying additional key-value pairs which are passed with the intent as `extras`. The keys must include a package prefix, for example the app `com.android.contacts` would use names like `com.android.contacts.ShowAll`.  
flags(optional)| `number`| Bitmask of flags to be used. See [Intent.setFlags](https://docs.expo.dev/versions/v52.0.0/sdk/intent-launcher/<https:/developer.android.com/reference/android/content/Intent.html#setFlags\(int\)>) for more details.  
packageName(optional)| `string`| Package name used as an identifier of ComponentName. Set this only if you want to explicitly set the component to handle the intent.  
type(optional)| `string`| A string specifying the MIME type of the data represented by the data parameter. Ignore this argument to allow Android to infer the correct MIME type.

Android
