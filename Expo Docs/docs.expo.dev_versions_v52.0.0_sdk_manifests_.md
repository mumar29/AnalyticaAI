## Installation[](https://docs.expo.dev/versions/v52.0.0/sdk/manifests/<#installation>)
Terminal
Copy
`- ``npx expo install expo-manifests`
If you are installing this in an [existing React Native app](https://docs.expo.dev/versions/v52.0.0/sdk/manifests/</bare/overview>), start by [installing `expo`](https://docs.expo.dev/versions/v52.0.0/sdk/manifests/</bare/installing-expo-modules>) in your project. Then, follow the [additional instructions](https://docs.expo.dev/versions/v52.0.0/sdk/manifests/<https:/github.com/expo/expo/tree/main/packages/expo-manifests>) as mentioned by the library's README under "Installation in bare React Native projects" section.
