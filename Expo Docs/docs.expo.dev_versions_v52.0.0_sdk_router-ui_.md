# Expo Router UI
[GitHub](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/<https:/github.com/expo/expo/tree/main/packages/expo-router> "View source code of expo-router-ui on GitHub")[npm](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/<https:/www.npmjs.com/package/expo-router-ui> "View package in npm Registry")
An Expo Router submodule that provides headless tab components to create custom tab layouts.
[GitHub](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/<https:/github.com/expo/expo/tree/main/packages/expo-router> "View source code of expo-router-ui on GitHub")[npm](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/<https:/www.npmjs.com/package/expo-router-ui> "View package in npm Registry")
Android
iOS
Web
`expo-router/ui` is a submodule of `expo-router` library and exports components and hooks to build custom tab layouts, rather than using the default [React Navigation](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/<https:/reactnavigation.org/>) navigators provided by `expo-router`.
> See the [Expo Router](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/</versions/v52.0.0/sdk/router>) reference for more information about the file-based routing library for native and web app.
## Installation[](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/<#installation>)

Copy
`- ``npx expo install expo-router`
## Configuration in app config[](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/<#configuration-in-app-config>)
If you are using the [default](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/</more/create-expo#--template>) template to create a new project, `expo-router` [config plugin](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/</config-plugins/introduction>) is automatically configured in the app config automatically.

### `TabTrigger`[](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/<#tabtrigger>)
Android
iOS
Web
Type: `React.Element<TabTriggerProps[](https://docs.expo.dev/versions/v52.0.0/sdk/router-ui/<#tabtriggerprops>)>`
Creates a trigger to navigate to a tab. When used as child of `TabList`, its functionality slightly changes since the `href` prop is required, and the trigger also defines what routes are present in the `Tabs`.
When used outside of `TabList`, this component no longer requires an `href`.
Example
```
<Tabs><TabSlot /><TabList><TabTrigger name="home" href="/" /></TabList></Tabs>

```
