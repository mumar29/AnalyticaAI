# ![Expo Speech icon](https://docs.expo.dev/static/images/packages/expo-speech.png)Expo Speech
[GitHub](https://docs.expo.dev/versions/v52.0.0/sdk/speech/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-speech> "View source code of expo-speech on GitHub")[npm](https://docs.expo.dev/versions/v52.0.0/sdk/speech/<https:/www.npmjs.com/package/expo-speech> "View package in npm Registry")
A library that provides access to text-to-speech functionality.
[GitHub](https://docs.expo.dev/versions/v52.0.0/sdk/speech/<https:/github.com/expo/expo/tree/sdk-52/packages/expo-speech> "View source code of expo-speech on GitHub")[npm](https://docs.expo.dev/versions/v52.0.0/sdk/speech/<https:/www.npmjs.com/package/expo-speech> "View package in npm Registry")
Android
iOS
Web
`expo-speech` provides an API that allows you to utilize Text-to-speech functionality in your app.
## Installation[](https://docs.expo.dev/versions/v52.0.0/sdk/speech/<#installation>)
Terminal
Copy

Then, follow the [additional instructions](https://docs.expo.dev/versions/v52.0.0/sdk/speech/<https:/github.com/expo/expo/tree/main/packages/expo-speech>) as mentioned by the library's README under "Installation in bare React Native projects" section.
## Usage[](https://docs.expo.dev/versions/v52.0.0/sdk/speech/<#usage>)
Speech
Copy
Open in Snack
```
import { View, StyleSheet, Button } from 'react-native';
import * as Speech from 'expo-speech';
export default function App() {
 const speak = () => {
  const thingToSay = '1';
  Speech.speak(thingToSay);
 };
 return (
  <View style={styles.container}><Button title="Press to hear some words" onPress={speak} /></View>
 );
}
const styles = StyleSheet.create({
 container: {
  flex: 1,
  justifyContent: 'center',
  backgroundColor: '#ecf0f1',
  padding: 8,
 },
});
```
