# React Native SVG
[GitHub](https://docs.expo.dev/versions/v52.0.0/sdk/svg/<https:/github.com/react-native-community/react-native-svg> "View source code of react-native-svg on GitHub")[npm](https://docs.expo.dev/versions/v52.0.0/sdk/svg/<https:/www.npmjs.com/package/react-native-svg> "View package in npm Registry")

> This library is listed in the Expo SDK reference because it is included in [Expo Go](https://docs.expo.dev/versions/v52.0.0/sdk/svg/<https:/expo.dev/go>). You may use any library of your choice with [development builds](https://docs.expo.dev/versions/v52.0.0/sdk/svg/</develop/development-builds/introduction>).
`react-native-svg` allows you to use SVGs in your app, with support for interactivity and animation.

### `Svg`[](https://docs.expo.dev/versions/v52.0.0/sdk/svg/<#svg>)
A set of drawing primitives such as `Circle`, `Rect`, `Path`, `ClipPath`, and `Polygon`. It supports most SVG elements and properties. The implementation is provided by [react-native-svg](https://docs.expo.dev/versions/v52.0.0/sdk/svg/<https:/github.com/react-native-community/react-native-svg>), and documentation is provided in that repository.

```
import Svg, { Circle, Rect } from 'react-native-svg';
export default function SvgComponent(props) {
 return (
  <Svg height="50%" width="50%" viewBox="0 0 100 100" {...props}><Circle cx="50" cy="50" r="45" stroke="blue" strokeWidth="2.5" fill="green" /><Rect x="15" y="15" width="70" height="70" stroke="red" strokeWidth="2" fill="yellow" /></Svg>
 );
}

```

### Pro tips[](https://docs.expo.dev/versions/v52.0.0/sdk/svg/<#pro-tips>)
Here are some helpful links that will get you moving fast!
  * Looking for SVGs? Try the [noun project](https://docs.expo.dev/versions/v52.0.0/sdk/svg/<https:/thenounproject.com/>).
  * Create or modify your own SVGs for free using [Figma](https://docs.expo.dev/versions/v52.0.0/sdk/svg/<https:/www.figma.com/>).
  * Optimize your SVG with [SVGOMG](https://docs.expo.dev/versions/v52.0.0/sdk/svg/<https:/jakearchibald.github.io/svgomg/>). This will make the code smaller and easier to work with. Be sure not to remove the `viewbox` for best results on Android.
  * Convert your SVG to an Expo component in the browser using [React SVGR](https://docs.expo.dev/versions/v52.0.0/sdk/svg/<https:/react-svgr.com/playground/?native=true&typescript=true>).
